# 暮瞳 DuskEye

一款免费、完全本地运行的 Windows 护眼工具,对标 [CareUEyes](https://care-eyes.com/) 的核心功能。
C# / .NET 8 WPF 原生实现,单文件 exe,无联网、无账户、无广告,代码完全属于你。

> 「暮瞳」——暮色时分的那双眼睛。图标是一枚「D」(DuskEye)花押,负空间藏着一弯新月;
> 程序内部标识仍为 `EyeCare`(程序集、配置目录 `%APPDATA%\EyeCare` 均沿用,升级无需迁移)。

![图标](src/EyeCare/Assets/icon.ico)

## 功能

### 🔍 护眼滤光(GPU 级)
- **蓝光过滤**:色温 1500K–6500K 无级调节,通过显卡 gamma 查找表(LUT)在 GPU 层面完成,
  **截图与录屏不受影响**,文字保持锐利(与 CareUEyes 同样的技术路线,优于普通覆盖式滤光)。
- **屏幕亮度**:10%–100%。≥50% 纯 gamma 实现;低于 50% 自动叠加鼠标穿透遮罩,实现深度调暗。
- **八档色彩预设**(与 f.lux 官方色温一致):1900K 烛光 / 2300K 暮色 / 2700K 白炽 / 3400K 夜间 /
  4200K 暖光 / 4800K 舒适 / 5500K 日光 / 5800K 阅读,点击即用;另有 4 组场景模式(色温+亮度组合)。
- **多显示器**:枚举所有活动显示器逐一应用。
- **拖动即所见**:色温/绿度/亮度滑杆边走边生效 —— 取值变化立刻进入一阶跟随(时间常数 40ms),
  不经过任何防抖,松手时画面已经到位;开关与模式切换仍走舒缓档(τ=250ms,约 0.9 秒视觉到位)。
- **自适应恢复**:锁屏、唤醒、显示器热插拔后自动重新应用(每 5 秒兜底校验)。
- **遮罩兜底**:个别环境(如远程桌面)系统拒绝 gamma 写入时,自动降级为半透明暖色遮罩。

### ⏰ 休息提醒
- 默认 **20-20-20 法则**:每 20 分钟,远眺 6 米外 20 秒,间隔与时长均可自定义。
- **强制休息**:全屏倒计时锁定(可选允许 3 秒后跳过)。
- **智能暂停**:检测到用户离开(无键鼠输入)自动暂停计时,回来后继续。
- 手动"立即休息"按钮。

### ⚙ 通用
- **开机自启**(写入 HKCU 注册表 Run 键,仅当前用户)。
- **定时护眼模式**:指定时间段(支持跨零点)自动切换夜间色温。
- **全局快捷键**:切换滤光 `Ctrl+Alt+E`,立即休息 `Ctrl+Alt+B`(可自定义)。
- 托盘常驻:**单击**托盘图标即唤回主界面(双击同样可以),右键菜单快速切换色调模式(色温/护眼绿/暗房)、
  色温预设、开关滤光、立即休息、退出;图标颜色指示滤光状态。

## 界面

设置窗口是**背景图 + 遮罩 + 哑光面板**三层,背景图可自选。设计原则只有一条:
**护眼软件本身不该是一个高光闪闪的界面**,所以亮部一律收敛(卡片顶边高光 11%、没有镜面反射、
柔光只有两团极淡的极光),背景也默认柔化到不抢注意力。

默认是「跟随桌面壁纸」——自动读取你当前的壁纸,在像素层模糊后当背景,所以既不单调也不刺眼。
在「外观」页可以换成自己的图片或退回内置渐变,并各自调浓度:

```
① 背景层   跟随桌面壁纸(默认,现读壁纸) / 自定义图片 / 内置哑光渐变
② 遮罩层   Theme.xaml → ScrimGlass,整层浓度由「背景遮罩浓度」滑杆控制
③ 面板层   Theme.xaml → GlassCardFill / GlassCardEdge,哑光深色卡片 + 一丝顶边高光
```

- **「跟随桌面壁纸」不是让窗口半透明去透出桌面。** 早期版本用未公开 API
  (`SetWindowCompositionAttribute`) 挂系统亚克力,实测对 `AllowsTransparency=True` 的
  分层窗口**无效**:调用返回成功、标志位也置真,但客户区根本不被模糊,透出来的是
  **清晰明亮、还在动的真实桌面** —— 对护眼软件完全是反效果。现在改为自己读壁纸、自己做模糊,
  结果完全可控,也不再依赖系统设置。
- 读不到壁纸(纯色桌面)或图片读不出来时,**自动降级**回内置渐变,降级原因写在页面上。
- 自定义图片会**复制**到 `%APPDATA%\EyeCare\backgrounds\background.<ext>`,
  之后删除或移动原文件都不受影响。跟随桌面则每次现读,不占额外空间。
- 两种「一张图」的背景,**模糊都在像素层做完再交给 `ImageBrush`**(降采样 → BlurEffect →
  RenderTargetBitmap),所以窗口四角的圆角永远是干净的;壁纸没有扩展名时按字节流解码,
  WIC 只认文件头,不看文件名。
- 布局:左侧烟熏导航栏(含当前状态胶囊)+ 右侧「Hero 总览卡 + 两栏栅格」,
  每页首屏即可看到当前状态与主操作,四页都不需要滚动。
- **文字清晰度有两条硬规矩**(踩过坑,写在这里免得复发):
  ① 承载文字的容器上**不许挂 `Effect`**。WPF 的 `Effect` 会把整个子树光栅化成中间纹理再过着色器,
     文字因此丢掉 ClearType、还会被非整数倍重采样 —— 表现就是"主界面文字发虚"。
     Hero 卡的琥珀光晕与强调按钮的发光因此都拆成了**独立的空层**(`HeroGlow`),与文字内容并排叠放。
  ② 窗口上开 `TextOptions.TextFormattingMode="Display"` + `UseLayoutRounding` + `SnapsToDevicePixels`:
     默认的 `Ideal` 用浮点字距排字,12px 上下的小字会发虚;`Display` 把字形推进对齐到整像素。
     注:窗口是分层窗口(`AllowsTransparency=True`,为了圆角),Windows 在这种情况下不提供 ClearType
     次像素抗锯齿 —— 这是拿"圆角无锯齿"换来的,属于已知取舍。
- 配置迁移:老版本升级上来时,背景来源若仍是旧的默认值「内置渐变」会被自动切到
  「跟随桌面壁纸」(只迁旧默认值,自己选过图片的不动)。见 `SettingsStore.Migrate`。

## 使用

直接运行 `EyeCare.exe`(单文件,无需安装任何运行时)。启动后**直接显示主界面**,同时驻留托盘。

| 命令行参数 | 作用 |
|---|---|
| (无参数) | 打开主界面并驻留托盘 |
| `--silent` / `--tray` | 静默驻留托盘,不弹界面(开机自启用) |
| `--settings` | 打开主界面(等价于无参数) |
| `--break` | 启动并立即休息一次 |

**窗口行为**:点「关闭」(或 Alt+F4)只是把界面收进托盘,滤光与休息提醒继续生效,不会退出程序。
唤回界面的方式有四种:单击托盘图标、双击托盘图标、托盘右键菜单「打开主界面」、
或**直接再运行一次 `EyeCare.exe`**(单实例,会把已有窗口叫到最前,不会弹「已在运行」提示框)。
彻底退出请用托盘右键菜单 →「退出」(退出时会恢复所有显示器 gamma)。
托盘右键的「色调模式」子菜单可直接切换 色温 / 护眼绿 / 暗房,不必先打开主界面。

配置与日志:`%APPDATA%\EyeCare\settings.json`、`log.txt`。

**退出与屏幕恢复**:通过托盘菜单"退出",程序会把所有显示器 gamma 恢复原始状态再退出。
(异常被强杀导致屏幕偏色时,可运行 `scripts/reset-gamma.ps1` 一键恢复。)

cd src\EyeCare
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ..\..\dist

## 项目结构

```
src/EyeCare/
├── App.xaml(.cs)          应用入口:单实例、命令行、服务装配
├── Core/
│   ├── GammaController    GPU gamma LUT、多显示器枚举、色温→通道换算
│   ├── OverlayManager     遮罩兜底层(鼠标穿透、置顶)
│   ├── FilterEngine       滤光总控:gamma 优先/遮罩兜底、定时模式、自动重应用
│   ├── BreakManager       休息计时引擎、空闲检测(智能暂停)
│   ├── BreakSession(.xaml) 全屏休息窗口(倒计时/进度条/跳过)
│   ├── TrayService        托盘图标(状态变色)、菜单、气泡
│   ├── HotkeyManager      全局热键注册
│   ├── AutoStartManager   开机自启(注册表)
│   ├── BackgroundStore    背景图:桌面壁纸定位、导入到数据目录、像素级高斯模糊、生成 ImageBrush
│   └── SettingsStore/Logger  配置持久化(含配置迁移)与日志
└── UI/
    ├── SettingsWindow(.xaml)  设置界面(滤光/休息/外观/通用 四页,分层背景布局)
    └── Theme.xaml             主题:色板 + 背景/面板资源 + 全部控件样式
```

## 设计参考

实现过程中参考了以下公开方案的设计与算法:

- **[redshift](https://github.com/jonls/redshift)**(开源,Linux/Windows):gamma ramp 色温调整的经典实现,
  其 `colorramp.c` 使用 Ingo Thies 黑体色表 + `(输入×亮度×白点)^(1/γ)` 变换。
  本项目在其基础上改用 Bradford 色适应 + 线性光空间计算,白点更准、灰阶更干净。
- **[LightBulb](https://github.com/Tyrrrz/LightBulb)**(开源 MIT,.NET/WPF,与本项目同技术栈):
  参考其平滑 gamma 过渡、日出日落时间表、应用白名单等设计。
  (本项目后来把过渡从"起点→终点 + 缓动曲线"换成了**一阶迟滞/指数跟随**:
  缓动曲线起点速度为零,而拖滑杆时目标每 16ms 被改写一次、每次都重排动画,画面就永远追不上手指。)
- **[f.lux](https://justgetflux.com/)**(闭源):参考其"色调变化永远平缓过渡"的理念
  (默认 30 分钟过渡窗口)与本项目的舒缓档过渡同源。
- **[Deepseek-Harness-Background-Customization](https://github.com/fuye-star/Deepseek-Harness-Background-Customization)**:
  参考其「整页背景 + scrim 压暗 + 半透明面板」的三层结构与可调旋钮思路(该插件用于 Web 页面,
  本项目把这套结构落到 WPF 桌面窗口上:背景层可换成桌面壁纸、自定义图片或内置渐变,
  遮罩浓度与背景模糊都是滑杆;①层没有沿用系统亚克力,而是自己读壁纸自己做模糊,原因见「界面」一节)。
